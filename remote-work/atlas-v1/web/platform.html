Contrôle passif autorisé — un bouton Scan, Policy Guard / RoE, exports unifiés.

API http://127.0.0.1:3001

Un clic lance AtlasLocal start (stack locale). Première fois : menu Démarrer → Atlas → Installer le stack, puis .env.

Scan réel : create mission → owner-authorization (stub local / Sign) → Circuit A (admin) → Policy Guard → web.passive.presence.v1 + suite shortlist → bilan JSON/CSV/PDF. Pas d’auto-execute avant approbation A. Authz locale : ATLAS_AUTHZ=signed (sans PRAGMA_SIGN_API_KEY qui masque ce chemin).

Admin Circuit A : ouvrir le client / admin — puis Reprendre ici (même mission, owner-auth déjà soumis).

RoE : *.pragma-cloud.com, *.pragma-serve.com, *.pragma.mc. Aucun secret dans ce binaire. Client complet : localhost:3002. Download public : atlas-secu.com/Atlas-Setup.exe.
